# Contributing To OrbitPay Contracts

## Local Work

Install Rust and Soroban tooling, then run:

```powershell
cargo test
soroban contract build
```

## Contribution Ideas

- Complete token transfer integration.
- Add event schema tests.
- Add expiry cancellation tests.
- Add deployment instructions.
- Add integration notes for `orbitpay-server`.

Security-sensitive changes should stay small and well tested.
